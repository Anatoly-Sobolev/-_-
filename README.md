# Работы к проверке

В репозитории находятся выполненные лабораторные работы по двум дисциплинам:

- `ООП` - объектно-ориентированное программирование;
- `РПО` - введение в разработку программного обеспечения.

## Пояснительные записки

Основные документы для проверки:

- `ООП/Пояснительная_записка_Лаб3_.docx`
- `ООП/Пояснительная_записка_Лаб4.docx`
- `ООП/Пояснительная_записка_Лаб5.docx`
- `РПО/Пояснительная_записка_ЛР9.docx`
- `РПО/Пояснительная_записка_ЛР10.docx`
